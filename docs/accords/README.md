# Accords écrits des sources

Un fichier par source : `<source>.md`. Une source sous accord (verdict C) n'est utilisée que si son accord est archivé ici.

Chaque fichier contient : la date, l'expéditeur et son adresse, la citation exacte de ce qui est autorisé (collecte, conservation, entraînement d'un modèle, affichage public), les limites et conditions (mention, lien, débit), et le lien vers le fil d'origine.
